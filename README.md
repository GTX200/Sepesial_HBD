# Website Bucin ❤️

Website romantis siap di-upload ke GitHub Pages.

## Struktur
- `index.html` — website utama
- `assets/foto1.jpg` sampai `foto6.jpg` — foto pasangan
- `assets/video.mp4` — video kenangan
- `assets/lagu.mp3` — musik
- `assets/poster.jpg` — poster video (opsional)

## Sebelum upload
Buka `index.html`, lalu edit bagian `Personalisasi`:
1. `whatsappNumber` → nomor WhatsApp pasangan, format internasional tanpa `+`.
2. `relationshipStart` → tanggal mulai hubungan.
3. Ubah teks romantis sesuai kisah kalian.
4. Masukkan foto/video/musik ke folder `assets`.

## GitHub Pages
Upload seluruh isi folder ke repository GitHub, lalu buka:
Settings → Pages → Deploy from a branch → pilih branch `main` dan folder `/ (root)` → Save.
